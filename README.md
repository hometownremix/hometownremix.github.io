# Hometown Remix Tracker

Every NHL team's record in its 2026-27 Hometown Remix jersey.

Live site: https://rjtribble.github.io/hometown-remix-tracker/

- `index.html` is the page.
- `data.js` holds every team's Remix schedule and results. To record a game, change its `null` to a result like `"W 4-2"`, `"L 1-3"` or `"OTL 3-4 OT"`, then update `UPDATED`.
